# Student Management System

A full-stack Student Management System built using React, Tailwind CSS, Node.js, and MongoDB.

This project helps manage students, admin operations, and educational data efficiently.

---

# 🚀 Tech Stack

## Frontend (Client)
- React.js
- Tailwind CSS
- Data Encryption

## Backend (Server)
- Node.js
- Express.js
- Data Encryption

## Database
- MongoDB

---

# 📁 Project Structure

```bash
Student/

├── client/     # Frontend React Application

```

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yogeshpriyadarshi/Student.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd Student
```

---

# 🖥️ Frontend Setup (Client)

## Go to Client Folder

```bash
cd client
```

## Install Dependencies

```bash
npm install
```

## Run Frontend

```bash
npm run dev
```

Frontend will start on:

```bash
http://localhost:5173
```

---

# 🛠️ Backend Setup (Server)

## Go to Server Folder

```bash
cd server
```

## Install Dependencies

```bash
npm install
```

## Build Server

```bash
npm run build
```

## Run Backend

```bash
npm run dev
```

Backend will start on:

```bash
http://localhost:5001
```

# 📦 Environment Variables

Create a `.env` file inside the `server` folder.

Example:

```env
PORT=5001
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
